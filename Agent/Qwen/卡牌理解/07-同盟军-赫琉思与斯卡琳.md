# 第一部分 · 赫琉思（8 张）

> 类型：射手 · **精灵 · 男** · 七位大贤者之一（弓箭手）
> 构成：天赋 2 张（施工中）+ 专属魔法 6 张（其中域外 2 张）
> 〔推算〕可收藏专属魔法副本 **6** ＋ 通用池 25 ＝ **31，距 40 张缺 9** → 无法单英雄构筑
> 〔推算〕带【限定】的牌 **6/8（75%）** —— 全项目最高比例

## 编组总览：一条从 1 费到 12 费的破防线

〔推算〕6 张专属魔法的费用与功能：

| 卡牌 | 品质 | 上限 | 费 | 功能 |
|---|---|---|---|---|
| 光芒尖端 | R | 2 | **1** | 解除一个单位的所有防御 |
| 普照 | L | 1 | 2 | 对所有目标 50 物理 + 抽一张 + 生成「光辉」 |
| 灼光 | L | 1 | 3 | 解除所有防御 + 100 物理 + 100 魔法 |
| 太阳蚀刻 | E | 2 | 3 | 压制 + 攻击力归零（两个敌方回合） |
| 光辉（域外） | — | — | 4 | 5×50 物理（优先防御最高）+ 生成「日冕」 |
| 日冕（域外） | — | — | **12** | 扣自己 100% 防御 + 对所有敌方单位 200 物理 + **溢出打信仰** |

〔推算〕**全 6 张都带【限定】** —— 赫琉思不在场，一张都用不了。〔推算〕这是全项目对英雄在场依赖度最高的编组（75%）。

〔推想〕对照莫伊卡（11%）：〔推算〕两位英雄代表两个极端。〔推想〕赫琉思是"体系即英雄"，莫伊卡是"体系独立于英雄"。

〔推算〕**破防线**是这套牌的核心动词：

| 卡牌 | 对防御力做什么 |
|---|---|
| 光芒尖端 | **解除全部防御**（直接清零防御状态） |
| 灼光 | 解除全部防御 **+ 200 点伤害** |
| 光辉 | 优先打**防御力最高**的单位 |
| 日冕 | 扣**自己**的全部防御，换取全体 200 |

〔推想〕四种不同的"处理防御力"的方式：**清零、清零并伤害、专挑最厚的、献出自己的**。

〔原典〕在这套规则里，防御力既是生命值也是资源（可被"回复"补满，见咏唱／伊莲女神的祝福）。〔推想〕**赫琉思的整套牌是对"回复体系"的直接否定**：你花 2 费回满 400D，他花 1 费全部解除。

〔推算〕经济对照：
- 伊莲女神的祝福（通用，2 费）：将一个单位回复至上限（最多 400D）
- 光芒尖端（赫琉思，1 费）：解除一个单位的所有防御

〔推想〕**1 费的解除 > 2 费的回满。** 〔推算〕只要赫琉思在场，对手的回复投资随时可能被清零。〔推想〕这让格兰蒂亚防线（400D 守护墙 + 2 费回满）在赫琉思面前失效。

〔留白〕"解除一个单位的所有防御"的确切含义：是清除"防御"这个行动产生的状态（〔原典〕防御效果会在下个己方回合开始时解除、每受一次攻击解除一层），还是把**防御力数值归零**？〔推算〕若是后者，则 1 费就能让一个 400D 的单位变成 0D（〔留白〕0D 是否等于消灭？原典未定义）。〔推想〕前者更符合"防御"这个词在原典中的用法（防御是一种行动状态，不是血量）。

## A. 天赋（2 张，施工中）

〔原典〕两张天赋的卡面：

> **天赋 1**：品质 E · 花费（施工中）· 面板（施工中）
> 【机动】**本单位可造成反击伤害**。（其余施工中）
>
> **天赋 2**：品质 L · 花费（施工中）· 面板（施工中）
> 【机动】**本单位攻击时，额外造成等同于攻击力的魔法伤害**。（其余施工中）

〔推算〕这两张天赋虽然数值未定，但**已经写出的两条规则都很有信息量**。

### 天赋 1：「本单位可造成反击伤害」

〔原典〕弓箭手：「造成物理伤害且无视守护。可攻击任意战区的目标，**不会受到也无法造成反击伤害**。」

〔推算〕**这条天赋规则直接推翻了弓箭手的核心限制之一。** 〔原典〕弓箭手有两条反击相关的免疫：①不会受到反击伤害 ②无法造成反击伤害。这张天赋只取消了 ②。

〔推算〕取消 ② 的意义：
- 正常弓箭手攻击一个 400D/100A 的守卫军 → 造成 A 点伤害，**不受反击** → 零风险
- 有此天赋后 → 造成 A 点伤害，**目标还受到 A 点反击伤害**（〔原典〕反击伤害 = "目标攻击力所对应的反击伤害"，此处指赫琉思的攻击力）

〔留白〕反击伤害的方向在原典中是"攻击者受到目标攻击力的反击"。若赫琉思"可造成反击伤害"，那么当**他攻击别人**时，别人是否也受到他的反击？这在语义上是反的（反击是被攻击时造成的）。〔推想〕更合理的读法是：**当他被攻击时，他能反击了**（原本"无法造成反击伤害"）。

〔推算〕若为此读法，则这张天赋让他从"零风险输出但也零威慑"变成"被攻击会反伤"。〔推想〕**对手不再能白打他。**

〔推算〕代价：〔留白〕面板施工中，无法评估。但按品质 E（对照伊芙格林的荆棘王冠 E、诺维安的新的勇者 E、莉莉亚的真理的钥匙 E）推测，它不会是最高档。

〔推想〕**这张天赋的设计意图是"让最脆的单位有活过一次交换的理由"** —— 这正是 dsh 归档页在编组 design 里写对的一句话。

### 天赋 2：「攻击时，额外造成等同于攻击力的魔法伤害」

〔推算〕效果：**每一箭射两遍**——一次物理（弓箭手本职）+ 一次等量的魔法。

〔推算〕这让他成为**混合伤害单位**。〔原典〕对照莉莉亚·纯粹学究的【防御】「使目标获得 **100 点物理伤害减免和 200 点魔法伤害减免**」——原典明确存在物理／魔法双轨减免。

〔推想〕**双轨伤害的价值在于绕过单轨防御**：一个把物理减免堆到 300 的单位，面对赫琉思仍要吃全额魔法伤害。

〔推算〕对照「魔力附加」（通用，3 费，「使一个战士或射手的下一次攻击附加 50% 的魔法伤害」）：
- 魔力附加：50% 攻击力，一次，3 费，需己方法师在场
- 天赋 2：100% 攻击力，**每次攻击**，常驻，无需法师

〔推想〕**天赋 2 是魔力附加的强化常驻版**，且倍率更高（100% vs 50%）。〔推算〕这也解释了为什么"魔力附加"这张通用牌在当前卡池里几乎没有启动路径（需己方法师，而通用池无法师）——**同盟军的射手自带了这个功能**。

〔留白〕「攻击时」的措辞：〔原典〕对照天罗地网「敌方单位**首次**攻击目标后」明确写了"首次"，此处未写 → 应为**每次攻击**。〔推想〕配合【奋战】（他没有任何奋战来源）或引风来（跨阵营，不可用），他一回合只攻击一次，所以"每次"与"首次"实际等价。

### 两张天赋的对照

| | 天赋 1（E） | 天赋 2（L） |
|---|---|---|
| 共同 | 【机动】 | 【机动】 |
| 差异 | 可造成反击伤害（**防御向**） | 攻击附加魔法伤害（**进攻向**） |
| 解决的问题 | 他太脆，被白打 | 他的物理伤害被减免 |

〔推算〕**两张天赋都带【机动】** —— 对照其他英雄：诺维安 3 张天赋中 1 张带机动（贤者的向往），莉莉亚 0 张，伊芙格林 2 张（荆棘王冠、与风同在），莫伊卡 1 张（天罗地网）。〔推想〕赫琉思的两张**全部**带机动，说明"入场即行动"对他是刚需。

〔推想〕为什么？〔原典〕弓箭手「可攻击**任意战区**的目标」+【机动】→ **他可以在入场的当回合，从战场任何位置射任何一个目标。** 〔推算〕这是全项目机动性最高的单位类型组合。

〔留白〕面板施工中 → 无法评估他的攻击力，因此破空类"等同攻击力"的伤害也无法估算。〔推算〕但他的 6 张专属魔法中**没有一张**写"等同于赫琉思攻击力"——全部是固定数值（50/100/200）或"解除防御"。〔推想〕**他的伤害与自己的面板无关**，这与诺维安（破空）、莉莉亚（凝聚冲击）、莫伊卡（奇袭）、斯卡琳（红月·过载）都不同。

## B. 专属魔法（6 张）

### 1. 光芒尖端（R，上限 2，1 费）

**卡面**〔原典〕
> 【限定】解除一个单位的所有防御。

**机制拆解**
1 费，解除一个单位的**所有**防御。〔推算〕全项目**最便宜的功能牌之一**，也是效果最绝对的一张（"所有"）。

〔留白〕"防御"的确切所指（见编组总览）。〔推算〕两种读法：
- **读法 A（状态清除）**：清除该单位身上由"防御行动"产生的效果（减伤、免疫、蓄能等），以及附着的防御层数
- **读法 B（数值归零）**：防御力降为 0

〔推算〕若为读法 B，则这张牌配合任何一点伤害都能击杀：1 费解除防御 → 芬特罗德 50A 一击杀掉 400D 的守卫军。〔推想〕这会强得离谱（1 费 = 一个 400D 单位），所以**读法 A 更可能**。

〔推想〕读法 A 下它的实际价值：清除格兰蒂亚守卫军的「50 点伤害减免」、结界护卫的「免疫一次伤害」、莉莉亚天赋的「100 物理 + 200 魔法减免」、纯粹学究给的减免、月见的 +100 防御力加成……〔推算〕**它是所有"防御投资"的清除键。**

〔推算〕受影响的具体卡牌（当前卡池）：

| 被清除的东西 | 来源 |
|---|---|
| 50 点伤害减免 | 格兰蒂亚守卫军【防御】 |
| 免疫一次伤害 | 格兰蒂亚结界护卫【防御】、荆棘王冠【防御】、伊芙格林【觉醒】【防御】、纯粹学究／真理的钥匙／苍白百合／莉莉亚觉醒的「永久免疫一次魔法伤害」 |
| 100 物理 + 200 魔法减免 | 纯粹学究【防御】 |
| +150/+100 临时面板 | 月见／弥望 |
| 蓄能状态 | 〔原典〕转换操作会"中止自身的蓄能"，光芒尖端是否也中止？〔留白〕未说明 |

〔推算〕**特别注意：莉莉亚的三张天赋与觉醒面板都给"永久获得：免疫一次魔法伤害"。** 〔留白〕"永久"的免疫能否被"解除所有防御"清掉？原典未说明。〔推想〕若能，则光芒尖端是莉莉亚体系的直接克星；若不能，则"永久"意味着不可清除。

**数值分析**
1 费 vs 灼光（3 费，解除所有防御 + 100 物理 + 100 魔法）。〔推算〕**灼光 = 光芒尖端 + 2 费 + 200 点双轨伤害。** 〔推想〕所以光芒尖端的定位是"纯粹的开锁"，灼光是"开锁并捅一刀"。

〔推算〕上限 2（光芒尖端）vs 上限 1（灼光）——〔推想〕开锁可以带两张，捅一刀只能带一张。

**构筑定位**
品质 R、上限 2、1 费、【限定】。〔推算〕必带满。

〔推算〕它是这套牌的**启动器**：先解除防御，再让后续伤害（普照、光辉、日冕）真正落地。〔推想〕对照莉莉亚的启动器是苍白之月（觉醒）、伊芙格林的是风之感知（计数）、莫伊卡的是她的梦想（永久改写）——**赫琉思的启动器是"让对手的防御不存在"**。

**叙事关联**〔推想〕
"光芒尖端"——〔推想〕"尖端"是箭头的部位。〔原典〕赫琉思是**精灵弓箭手**。

〔推想〕一支箭的尖端是光的（金属反光），而这张牌的效果是"解除防御"——〔推想〕**箭头挑开了盾**。

〔推算〕他的 6 张牌名：光芒尖端、灼光、太阳蚀刻、普照、光辉、日冕。〔推算〕**全部是光／太阳意象**，无一例外。〔推想〕对照：
- 莉莉亚：苍白之月、月见、弥望、逐月、苍白天球、苍白缄默 → **月**
- 伊芙格林：狂风呼啸、引风来、强风骤雨、长风破袭、苍叶、树人 → **风与林**
- 诺维安：旅途的起点、漫漫长路、征途、勇气、未来、新章、故事与歌 → **路**
- 斯卡琳：绯红原质、绯红之月、红月四式、绯红的真实、阿波罗经络 → **红月与太阳神**
- 莫伊卡：陷阱、枷锁、天罗地网、无踪无迹 → **网与锁**
- **赫琉思：光芒、灼光、太阳、普照、光辉、日冕 → 太阳**

〔推想〕**赫琉思与斯卡琳共享"太阳"意象**（赫琉思的太阳／光，斯卡琳的阿波罗＝太阳神），而两人都属**同盟军**。〔推想〕同盟军的意象系统是**光**，魔王军的是**梦与影**（见 `06-米莉卡与莫菲.md`），新的勇者的是**自然与道路**。

〔原典〕真相节：斯卡琳「在愤怒中升起了**红月**」。〔推想〕**一位太阳阵营的魔法师，升起了红色的月亮**——她背叛了自己阵营的意象。〔留白〕归档者的联想。

〔原典〕赫琉思「作为唯一能见到五百年后的世界的精灵，在荷珀死后无法找到希望，**不知所踪**」。〔推想〕一个太阳意象的英雄，在失去朋友后消失了。〔推想〕**光熄灭了。**

〔原典〕他还有一张牌叫「太阳蚀刻」——〔推想〕"蚀"是日蚀。〔推想〕太阳被刻蚀。〔留白〕原典未说明命名意图。

**存疑与留白**
- "解除所有防御"是清状态还是归零防御力？
- 能否清除"永久获得"的免疫效果？
- 能否指向信仰？（信仰有 1000 点防御力；"一个单位"——信仰是"对象"）
- 能否指向己方单位？（未限定敌我）

### 2. 灼光（L，上限 1，3 费）

**卡面**〔原典〕
> 【限定】解除一个单位的所有防御，对其造成100点物理伤害与100点魔法伤害。

**机制拆解**
3 费：解除所有防御 + **100 物理 + 100 魔法**（两种伤害并列写出）。

〔推算〕**全项目唯一一张明确写出双轨固定伤害的牌**（对照魔力附加是"附加 50% 的魔法伤害"，天赋 2 是"额外造成等同于攻击力的魔法伤害"，都不是固定值）。

〔推算〕200 点总伤害的击杀线：

| 目标 | 防御力 | 结果 |
|---|---|---|
| 苍叶 | 50 | 死 |
| 芬特罗德／伊芙格林三天赋／天罗地网 | 100 | 死 |
| 兜帽怪盗 | 150 | 死 |
| 莉莉亚三天赋／伊芙格林觉醒 | 200／250 | 死（200 正好） |
| 诺维安天赋 | 250／250／300 | 死／死／**剩 100** |
| 树人 | 300 | 剩 100 |
| 格兰蒂亚守卫军／结界护卫 | 400 | 剩 200 |

〔推算〕**200 点能一击消灭当前卡池中除格兰蒂亚两张与旅途的起点／树人以外的所有单位。** 〔推想〕而且因为**先解除防御**，目标的任何减免／免疫都被清掉，200 点是**实打实的**。

〔推想〕对照凝聚冲击（莉莉亚，4 费，等同攻击力魔法伤害，最高 350）：灼光更便宜（3 费）、更稳定（固定 200 而非依赖面板）、且是双轨（绕过单轨减免）。〔推算〕**灼光是当前卡池中性价比最高的单体解。**

〔推算〕但上限 1（孤本），且带【限定】。

**数值分析**
〔推算〕为什么是 100 + 100 而不是 200 物理？〔推想〕因为**双轨伤害无法被单一减免抵消**：
- 一个有 100 点物理减免的单位：受 0 物理 + 100 魔法 = 100
- 一个有 200 点魔法减免的单位：受 100 物理 + 0 魔法 = 100
- 一个两者都没有的单位：受 200

〔推算〕当前卡池中同时具备双轨减免的只有**纯粹学究**（100 物理 + 200 魔法）→ 它受 0 + 0 = **0 伤害**。〔推想〕**纯粹学究是灼光的完美克星**，而两者分属不同英雄（莉莉亚 vs 赫琉思，但同阵营"新的勇者" vs "同盟军" → 跨阵营，永不同框）。

〔推想〕所以在实际对战中，灼光的 200 点几乎总是完整的。

**构筑定位**
品质 L、上限 1、3 费、【限定】。〔推算〕必带，是主要的单体解。

〔推算〕与光芒尖端的分工：
- 光芒尖端（1 费 ×2）：便宜、可重复、只解除防御 → 用于给普照／光辉／日冕铺垫
- 灼光（3 费 ×1）：解除 + 击杀 → 用于解决单个威胁

**叙事关联**〔推想〕
"灼光"——〔推想〕"灼"是烧灼。〔推算〕这是 6 张牌中唯一带**伤害感**的名字（光芒尖端是部位、太阳蚀刻是现象、普照是范围、光辉是状态、日冕是结构）。

〔推想〕"灼光"的效果是"解除防御 + 200 点双轨伤害"——〔推想〕**光烧穿了盾，然后烧进了肉里。**

〔原典〕赫琉思是七位大贤者中唯一活到当代的精灵。〔原典〕真相节：「其他五位大贤者见红月升起，赶往荷珀与斯卡琳的住处，但均**没有抵抗得了红月的侵蚀**，在半途就失去了意识。」

〔推想〕他见过红月，并且没能抵抗它。〔推想〕而他此后的所有牌都是**光与太阳**。〔推想〕一个被红月击倒的人，用余生研究光。

〔留白〕归档者的联想，原典未描写赫琉思的心理或后续经历，只说"不知所踪"。

**存疑与留白**
- 双轨伤害的结算顺序（先物理后魔法？同时？）
- 若目标有"免疫一次伤害"，免疫的是哪一部分？（物理、魔法、还是两者？）
- 解除防御与造成伤害的结算顺序（应先解除，否则减免会生效）

### 3. 太阳蚀刻（E，上限 2，3 费）

**卡面**〔原典〕
> 【限定】**压制**一个单位并使其**攻击力为0**，若为英雄，则其专属魔法无法使用，**直到两个敌方回合结束**。

**机制拆解**
三段：
1. **压制**一个单位 → 〔原典〕压制「使一个单位无法行动；若为英雄，其带有限定的专属魔法无法使用。**单位所有者回合结束时，解除压制**。」
2. 使其**攻击力为 0**
3. **直到两个敌方回合结束**

〔推算〕**注意第 3 段与压制的默认规则冲突**：压制默认"单位所有者回合结束时解除"（即一个回合），但此卡明写"直到两个敌方回合结束"。〔推想〕所以这张牌**延长了压制的持续时间**，并且让"攻击力为 0"这个效果也持续两个敌方回合。

〔推算〕与禁锢的对比：

| | 压制（太阳蚀刻） | 禁锢（枷锁等） |
|---|---|---|
| 无法行动 | ✓ | ✓ |
| 英雄的【限定】专属魔法失效 | ✓ | ✓ |
| 默认解除 | 所有者回合结束时 | 被防御后（该次防御无效） |
| 太阳蚀刻的时长 | **两个敌方回合** | — |
| 攻击力归零 | **✓（本卡附加）** | ✗ |
| 解除方式 | 时间到 | 有人防御它 |

〔推想〕**太阳蚀刻是"硬控"，禁锢是"软控"**：
- 禁锢可以被"防御"撬开（代价是那次防御白费）
- 压制**只能等时间到**，无法被主动解除

〔推算〕"攻击力为 0"的独立价值：〔原典〕攻击时"同时受到目标攻击力所对应的反击伤害"。〔推算〕**攻击力为 0 的单位，即使解除压制后攻击，也不造成任何伤害，也不产生反击威慑。**

〔推想〕对特定目标的毁灭性：
- **诺维安**（150A，破空＝等同攻击力）→ 攻击力归零后，破空造成 **0 伤害**
- **莉莉亚**（200A，凝聚冲击＝等同攻击力）→ 凝聚冲击 **0 伤害**
- **莫伊卡**（50A，奇袭＝等同攻击力）→ 奇袭 **0 伤害**
- **斯卡琳**（红月·过载＝等同攻击力）→ **0 伤害**
- **伊芙格林**（御风都是固定值，不受攻击力影响）→ 影响较小

〔推算〕**当前卡池中 5/8 位英雄的主要伤害来源是"等同于英雄攻击力"** → 太阳蚀刻能一次性废掉他们全部输出。〔推想〕这是全项目**最强的反英雄牌**，而且只要 3 费。

〔推算〕对照斯卡琳的「绯红的真实」（18 费）：「使**除斯卡琳外的所有单位攻击力为 0**，直到下个己方回合结束」——〔推想〕**同一个"攻击力归零"机制，赫琉思 3 费单体两回合，斯卡琳 18 费全场一回合。**

**数值分析**
3 费、E 品质、上限 2、【限定】。〔推算〕对照灼光（3 费，L，上限 1，解除防御 + 200 伤害）：

| | 太阳蚀刻 | 灼光 |
|---|---|---|
| 费 | 3 | 3 |
| 上限 | **2** | 1 |
| 效果 | 压制 + 攻击力归零，两个敌方回合 | 解除防御 + 200 双轨伤害 |
| 解决方式 | **控制**（不杀） | **击杀** |

〔推想〕同价位的两种答案：一个锁住，一个杀掉。〔推算〕锁住的好处是**不消耗对手的资源**（对手的单位还在场上，但没用），杀掉的好处是**永久移除威胁**。

〔推算〕对英雄而言，锁住更有效（英雄有【返场】，杀了会回来）。〔推想〕**太阳蚀刻是专门用来对付英雄的牌**：压制 + 攻击力归零 + 【限定】专属魔法失效，三重封锁，持续两个敌方回合。

**构筑定位**
品质 E、上限 2、3 费、【限定】。〔推算〕必带满 2 张。

〔推算〕两张太阳蚀刻可以**接力**：第一张压制两个敌方回合，快到期时打第二张 → **连续四个敌方回合的封锁**。〔推想〕这是全项目最长的单体控制链。

**叙事关联**〔推想〕
"太阳蚀刻"——〔推想〕"蚀刻"（etching）是一种工艺：用酸或刀在表面刻出纹路。〔推想〕"太阳的蚀刻"= 被太阳刻下的痕迹，或**把太阳刻上去**。

〔原典〕日蚀（eclipse）在天文上是月亮遮挡太阳。〔推想〕而"蚀刻"是主动的雕刻。〔推想〕这个卡名有双关：**日蚀（被遮挡）与蚀刻（被铭刻）**。

〔原典〕真相节：斯卡琳「在愤怒中升起了**红月**」——〔推想〕**红月升起，太阳被蚀。**

〔推想〕赫琉思的这张牌名叫"太阳蚀刻"，效果是**压制**（让对方无法行动、攻击力归零、专属魔法失效）。〔推想〕红月升起的那一刻，五位大贤者「均没有抵抗得了红月的侵蚀，在半途就失去了意识」——〔推算〕**他们被压制了。**

〔推想〕"太阳蚀刻"是赫琉思对那一夜的复现：太阳被蚀，人被压制，攻击力归零（无法抵抗），专属魔法失效（红月侵蚀下失去意识）。

〔留白〕这是归档者基于原典真相节与卡名／效果对应的推想。原典未说明这张牌的叙事意图，也未说明赫琉思是否记得那一夜（原典只说他们"醒来后仅得知"官方版本）。

〔推想〕**如果他记得，这张牌是他唯一能做的事：把那一夜变成一个技能。** 〔原典〕"醒来后仅得知「斯卡琳在钻研禁术中失控，而使丈夫、孩子以及前来护卫的军队失去了生命」"——他被喂了假消息。〔原典〕「唯有赫琉思知晓欧若拉留下的预言的全貌」。

**存疑与留白**
- "直到两个敌方回合结束"由谁的回合计数？
- 压制与"攻击力为 0"是否同时到期？
- 能否指向信仰？（信仰无法行动，攻击力本就不适用）
- 两次压制同一目标是否刷新时长还是叠加？
- 「若为英雄，则其专属魔法无法使用」——原典压制的定义是"带有限定的专属魔法"，此处写"专属魔法"（无限定词），是否意味着**连不带限定的专属魔法也失效**？〔推算〕若如此，则比禁锢更狠（对照莫伊卡只有天罗结界带限定，被太阳蚀刻后她的陷阱／枷锁／奇袭也全部失效）

### 4. 普照（L，上限 1，2 费）

**卡面**〔原典〕
> 【限定】对所有目标造成50点物理伤害，抽一张牌。将一张「光辉」**加入卡组**。

**机制拆解**
三段：
1. 对**所有目标**造成 50 点物理伤害
2. 抽一张牌
3. **生成**一张「光辉」（域外，4 费）加入卡组（〔作者明确〕"加入"= 印制新卡）

〔留白〕"所有目标"——是敌方全体，还是双方全体？〔推算〕对照光辉写"若无敌方单位，施加至**敌方信仰**"、日冕写"对所有**敌方单位**"，此处只写"所有目标"。〔推想〕按上下文应指敌方，但原典用词不严谨。

〔留白〕"目标"是否包含信仰？（对照长风破袭明确写"信仰除外"，此处未写）

〔推算〕这是**光辉 → 日冕**链条的第一环，而**三级全部用"加入卡组"（生成）**：

```
普照（2 费，可收藏，上限 1）
   ↓ 生成
光辉（4 费，域外）
   ↓ 生成
日冕（12 费，域外）
```

〔推想〕这是一个**三级火箭**：每一级都由上一级**生成**（印制）出来。〔推算〕对照斯卡琳的四级转化链（绯红原质→灵究→极限→之月，用"转化"）与莉莉亚的觉醒链（苍白百合→苍白之月→觉醒，用"转换"）——**三位英雄各有一条多级链条，但机制各不相同**：

| 英雄 | 链条机制 | 级数 | 是否可收藏入口 |
|---|---|---|---|
| 赫琉思 | **加入卡组**（生成下一级，凭空印制） | 3 | 普照（2 费，上限 1） |
| 斯卡琳 | **转化**（把其余同名牌升级，卡数不变） | 4 | 绯红原质（2 费，上限 4） |
| 莉莉亚 | **蓄能 → 中介牌 → 觉醒 → 转换** | 3 | 苍白百合（天赋）+ 苍白之月（2 费，上限 2） |

〔推想〕三种机制的差异很本质：赫琉思的链条是"**生成**"（每级都新印一张，卡组膨胀）；斯卡琳的是"**转化**"（把手上/库里的同名牌升级，卡组张数不变）；莉莉亚的是"**转换**"（一张卡变成另一张，见原典卡牌操作）。〔推想〕这正好对应原典三个不同的动词，作者用得毫不含糊。

〔推算〕赫琉思链条的脆弱点也因此清晰：**普照上限 1**（孤本），抽不到就整条链断掉；但只要抽到并打出普照，光辉是**生成**的（必然进卡组），日冕也是生成的——所以链条一旦启动就不会因为"牌库里没有下一级"而断，只会因为"没抽到普照"而根本启动不了。

**数值分析**
2 费：全体 50 点物理 + 抽一张 + 生成光辉。

〔推算〕50 点全体伤害的击杀线：苍叶（50D）。〔推想〕对绝大多数单位只是削血。

〔推算〕但它的价值不在伤害，在**抽牌 + 生成**。〔推想〕2 费换一张牌 + 一条链的启动，这是全项目最便宜的链条入口（对照绯红原质也是 2 费，苍白之月也是 2 费——〔推算〕**三位英雄的链条入口都是 2 费**）。

〔推想〕这是一个刻意的统一定价：**链条的第一步总是便宜的，代价在后面。**

| 链条 | 各级费用 | 总投入 |
|---|---|---|
| 赫琉思 | 2 → 4 → 12 | **18 费** |
| 斯卡琳 | 2 → 3 → 5 → 7 →（红月 5×4）→ 18 | **约 40+ 费** |
| 莉莉亚 | 4（天赋）→ 2×2（蓄能行动）→ 2（苍白之月） | **约 10 费** |

〔推算〕赫琉思的链条总投入 18 费，与斯卡琳的终极牌（绯红的真实 18 费）**数字相同**。〔推想〕两位同盟军英雄的最高点都是 18 这个数字——一个是最贵单卡的费用，一个是链条三级的总和。

**构筑定位**
品质 L、上限 1、2 费、【限定】。〔推算〕必带（唯一的链条入口）。

〔推想〕风险：上限 1 + 【限定】+ 需要赫琉思在场。〔推算〕若他被消灭，普照不可用，光辉与日冕永远不会进入卡组。

〔推算〕对照斯卡琳的绯红原质（上限 **4**）——〔推想〕斯卡琳的链条入口可以带 4 张，抽到的概率高得多；赫琉思只有 1 张。〔推算〕**赫琉思的链条可靠性远低于斯卡琳。**

**叙事关联**〔推想〕
"普照"——〔推想〕"普"是普遍、无处不及；"照"是光照。〔推想〕**阳光普照大地，不分对象。**

〔推算〕它的效果正是"对**所有目标**造成 50 点伤害"——〔推想〕不选择、不偏向、无处可躲。

〔推想〕这是 6 张牌中最"太阳"的一张：光芒尖端（箭尖的一点）、灼光（烧灼的一处）、太阳蚀刻（被刻蚀的一刻）、**普照（覆盖一切）**、光辉（明亮）、日冕（太阳的外层）。

〔原典〕赫琉思「作为唯一能见到五百年后的世界的精灵，在荷珀死后无法找到希望，不知所踪」。〔推想〕一个"普照"一切的人，最后自己消失了。

〔推想〕而"普照"生成的是"**光辉**"，光辉生成的是"**日冕**"。〔推算〕日冕（corona）是太阳大气的最外层——〔推想〕**只有发生日全蚀时，日冕才可见**。〔推想〕所以从"普照"到"光辉"到"日冕"，是一条**从可见到只在遮蔽时可见**的路径。

〔推想〕而日冕的效果是「扣取赫琉思当前防御力的 **100%**」——〔推想〕**他把自己扣光，才能看见日冕。** 这与"日全蚀时日冕可见"的天文事实完全对应。

〔留白〕归档者的推想，原典未说明命名意图。但这个对应的精确度（日冕只在太阳本体被遮住时可见 ↔ 扣光自己的防御力才能发动）不像巧合。

**存疑与留白**
- "所有目标"是否包含己方？是否包含信仰？
- 生成的光辉放入卡组的位置（顶／底／随机）
- 若卡组中已有光辉，再生成一张会怎样？（光辉是域外牌，无上限概念 → 会累积多张，卡组膨胀）

### 5. 光辉（域外，4 费）

**卡面**〔原典〕
> 【限定】造成**5次50点**物理伤害，**优先施加至防御力最高的敌方单位**。若无敌方单位，施加至敌方信仰，抽一张牌。将一张「日冕」**加入卡组**。

**机制拆解**
四段：
1. 5 次 × 50 点物理伤害（总 250）
2. **优先施加至防御力最高的敌方单位**
3. 若无敌方单位 → 施加至敌方**信仰** + 抽一张牌
4. **生成**一张「日冕」（12 费域外）加入卡组

〔推算〕**"优先施加至防御力最高的敌方单位"是全项目唯一的智能分配规则**。〔推想〕对照：
- 强风骤雨（伊芙格林）：随机分配
- 狂风呼啸（伊芙格林）：定向 + 尽可能多的目标 + 溢出回流
- 红月·过载（斯卡琳）：平均分配
- 大奇迹（米莉卡）：随机分配
- **光辉（赫琉思）：优先最高防御**

〔推想〕**这是一种"破甲"分配逻辑**：把伤害集中到最厚的墙上。〔推算〕250 点集中打一个 400D 的格兰蒂亚守卫军 → 剩 150D；配合光芒尖端（先解除防御）→ 效果更佳〔留白〕解除防御后它还是"防御力最高"吗？

〔推算〕5 次 × 50 的**分段**结构很重要：〔原典〕格兰蒂亚结界护卫的【防御】是"免疫**一次**伤害"。〔推想〕分 5 次的话，免疫只挡掉 1 次（50 点），剩余 200 点仍生效。〔推算〕**分段伤害天然克制"免疫一次"类效果。**

〔推算〕对照"50 点伤害减免"（守卫军）：若减免是每次伤害减 50，则 5 次 × (50−50) = **0 伤害**。〔推想〕所以守卫军的减免恰好完全抵消光辉的每一段——〔留白〕这是一个精确到可疑的数值对应（50 减免 vs 50 伤害/段）。

〔推算〕第 3 段"若无敌方单位，施加至敌方信仰"——〔推想〕这是一条**兜底条款**，保证清场后这张牌不浪费。〔推算〕250 点打信仰（1000D）= 25%。

**数值分析**
4 费、域外。〔推算〕等效：4 费换 250 点智能分配伤害 + 抽一张（若无单位）+ 生成日冕。

〔推算〕对照狂风呼啸（伊芙格林，6 费，扣 50% 血，200 定向 + 4×50 分散，溢出回流）：
- 光辉：4 费，250 点，优先最高防御，无代价
- 狂风呼啸：6 费，400 点（上限），定向 + 分散，扣 50% 血

〔推想〕光辉更便宜、无代价、分配更聪明；狂风呼啸总量更高但需扣血。

**构筑定位**
域外，不占构筑位。〔推算〕唯一来源是普照（上限 1）。

〔推想〕它是链条的**中间级**：本身是强力的 AOE，同时生成日冕。〔推算〕所以即使不追求日冕，光辉本身就值得打出。

**叙事关联**〔推想〕

### 6. 日冕（域外，12 费）

**卡面**〔原典〕
> 【限定】扣取赫琉思当前防御力的**100%**，对所有敌方单位造成**200点**物理伤害，**溢出的伤害施加至敌方信仰**。

**机制拆解**
三段：
1. 扣取赫琉思**当前**防御力的 100%
2. 对所有敌方单位造成 200 点物理伤害
3. **溢出的伤害施加至敌方信仰**

〔推算〕**"溢出"是全项目独有的机制**（对照永恒的记忆只写"对所有敌方单位造成300点物理伤害"，无溢出条款）。

〔推算〕溢出的计算：若某敌方单位防御力 < 200，则超出部分为溢出。〔留白〕溢出是逐个单位计算还是总量计算？〔推想〕按字面应是**每个单位的溢出量累加**，全部打向信仰。

| 敌方场面 | 各单位溢出 | 打信仰总量 |
|---|---|---|
| 空场 | — | **0**（没有单位就没有溢出？〔留白〕） |
| 1 个苍叶（50D） | 150 | 150 |
| 3 个苍叶 | 450 | 450 |
| 4 个伊芙格林天赋（100D） | 400 | 400 |
| 1 个格兰蒂亚守卫军（400D） | 0 | 0 |
| 8 个苍叶 | 1200 | **1200 > 1000 → 信仰被摧毁** |

〔推算〕**关键发现：日冕对信仰的伤害取决于敌方单位的数量与血量，单位越脆越多，信仰受伤越重。**

〔推想〕这是一个**反向的铺场惩罚**：对手铺越多脆皮单位，日冕的溢出伤害越高。〔推算〕对照伊芙格林（能铺 4 苍叶 + 4 树人）与诺维安（格兰蒂亚两张 + 芬特罗德）——〔推想〕**铺场型卡组会被日冕反噬**。

〔推算〕但注意：树人 300D、守卫军 400D 都 < 200？不，300 > 200、400 > 200，所以它们**不产生溢出**。〔推想〕只有 D < 200 的单位才产生溢出。〔推算〕当前卡池中 D < 200 的单位：苍叶(50)、芬特罗德(100)、伊芙格林三天赋(100)、天罗地网(100)、兜帽怪盗(150)。

〔推想〕**日冕的最优目标是"一群脆皮"，最怕的是"几面厚墙"。**

〔留白〕**空场时是否直接打信仰？** 卡面写"对所有敌方单位造成 200 点物理伤害，溢出的伤害施加至敌方信仰"——若没有敌方单位，则没有伤害也没有溢出，信仰受 0。〔推算〕对照光辉明确写了"若无敌方单位，施加至敌方信仰"作为兜底，**日冕没有这个兜底**。〔推想〕所以日冕在空场时**完全无效**——这是一个设计缺口。

**数值分析**
12 费、扣 100% 自身防御。〔推算〕**12 费正好是自然魔力上限**，所以最早第 12 回合可打。

〔推算〕"扣取当前防御力的 100%" → 他的防御力变为 **0**。〔留白〕0 防御力是否等于消灭？（同伊芙格林的永恒的记忆，全项目关键留白）

## 编组总览：两套体系，共用一位英雄

〔推算〕斯卡琳的 10 张牌分成**两个独立的体系**：

**体系 A：绯红转化链（4 张，推高魔力上限）**

绯红原质（R，2 费，上限 4）：+1 上限，将其余转化为绯红灵究
   ↓
绯红灵究（域外，3 费）：+1 上限，抽一张魔法，将其余转化为绯红极限
   ↓
绯红极限（域外，5 费）：+2 上限，抽两张魔法并减一费，将其余转化为绯红之月
   ↓
绯红之月（L，7 费，上限 1）：+3 上限，随机给一张红月，使斯卡琳觉醒
```

**体系 B：红月四式（4 张，全部域外、全部【限定】、全部带（红月）标注）**

红月·凝刻（5 费）：+150/+200，手牌中所有红月减二费

红月·过载（5 费）：在手牌时每使用一张红月减一费；等同攻击力的魔法伤害平均分配
红月·凝聚（8 费）：+3 上限，将凝刻与无限加入手牌
```

**终点：绯红的真实（域外，18 费，【限定】）**
```
使用过五张「红月」后加入手牌；在手牌时每使用一张红月减一费
→ 除斯卡琳外所有单位攻击力为 0，直到下个己方回合结束
→ 下个己方回合开始时给三张 0 费红月

```

**外加：阿波罗经络（E，5 费，上限 1）** —— 检索牌，独立于两个体系。

〔推算〕**体系 A 是体系 B 的前提**：红月四式全部是域外牌，唯一来源是绯红之月（"随机将一张「红月」加入手牌"）与红月·凝聚（"将一张「红月·凝刻」与「红月·无限」加入手牌"）。

〔推算〕而绯红的真实需要"**使用过五张红月**"——〔推算〕红月四式的可获得量：
- 绯红之月：随机给 1 张（4 种之一）
- 红月·凝聚：给凝刻 + 无限（2 张）
- 红月·无限：「己方回合结束时，若手牌中没有『红月·无限』，将一张加入手牌」→ **自我补充**

〔推想〕**红月·无限是这套体系的"呼吸"**：只要打出它，回合结束就会回到手上。〔推算〕所以它可以被**反复使用**，每次使用都计入"使用过五张红月"的计数。

〔推算〕达成 5 张红月的最短路径：
1. 绯红原质（2 费）→ +1 上限
2. 绯红灵究（3 费）→ +1 上限，抽 1 魔法
3. 绯红极限（5 费）→ +2 上限，抽 2 魔法并减费
4. 绯红之月（7 费）→ +3 上限，随机给 1 张红月，觉醒 → **红月计数 0**
5. 打出随机红月（5 费）→ **计数 1**
6. 红月·凝聚（8 费）→ +3 上限，给凝刻 + 无限 → 打出凝刻（5 费）**计数 2**、打出无限（5 费）**计数 3**
7. 无限回合结束回手 → 再打（5 费）**计数 4**
8. 再回手 → 再打 **计数 5** → **绯红的真实加入手牌**

〔推算〕魔力总投入：2+3+5+7+5+8+5+5+5+5 = **50 点**，跨越至少 **8～10 个回合**（受每回合魔力上限限制）。〔推算〕魔力上限需达到：第 10 回合自然 10，加转化链 +7（1+1+2+3）+ 凝聚 +3 = **20**，硬上限 24 之内 ✓。

### 1. 阿波罗经络（E，上限 1，5 费）

**卡面**〔原典〕

### 4. 绯红极限（域外，5 费）

**卡面**〔原典〕
> 额外获得两点魔力上限，**抽两张魔法，使其花费减一**。将其余「绯红极限」转化为「绯红之月」。

> ⚠️ **dsh 归档页漏抄了「抽两张魔法，使其花费减一」**（见 `纠错与更正.md` B8）

**机制拆解**
5 费：+2 上限 + 抽 2 魔法并各减一费 + 转化其余为之月。

〔推算〕**"使其花费减一"**——减的是刚抽到的那两张。〔留白〕减费是永久还是本回合？（对照远方的憧憬"抽一张牌，使其获得减一花费"，同样未写时限）

〔推想〕减费的意义：链条本身很贵（2+3+5+7 = 17 费），而减费让后续的牌更容易打出。〔推算〕特别是把红月四式（各 5 费）减到 4 费，或把绯红的真实（18 费）减到 17 费。

〔推算〕"抽两张魔法并减费"配合"红月·过载"（在手牌中每使用一张红月减一费）与"红月·凝刻"（手牌中所有红月减二费）→ **三重减费来源**。

〔推算〕绯红的真实的减费账：
- 基础 18 费
- 「使用过五张红月后加入手牌。在手牌中时，**每使用一张红月，获得减一花费**」→ 理论上可减很多
- 若已使用 5 张才入手，则入手后每再使用一张红月 −1

〔留白〕"每使用一张红月获得减一花费"是否有上限？若它入手后又使用了 5 张红月 → 18−5 = **13 费**。〔推算〕仍需魔力上限 ≥13，而链条给 +7 → 12+7 = 19 ✓。

**数值分析**
5 费、+2 上限、抽 2 减 1。〔推算〕这是链条中**收益最高的一级**（+2 上限 > 前两级的 +1）。

〔推想〕对照 dsh 归档页的解读「到这里，一条 2+3+5 = 10 费的投资已经能把上限推过 12」——〔推算〕**这个算术是错的**：2+3+5 = 10 费，但上限增量是 1+1+2 = **+4**，12 − 4 = 8，第 8 回合自然上限才到 8……〔推算〕正确算法：自然上限第 N 回合为 N，加上链条 +4 → 第 8 回合可达 **12**。〔推想〕所以"推过 12"需要第 9 回合 + 完整链条，且还需绯红之月的 +3。

〔推算〕dsh 的"10 费投资"混淆了**费用支出**与**上限增量**，且漏掉了两级（之月 +3、凝聚 +3）。

**构筑定位**

**叙事关联**〔推想〕

### 6. 红月·凝刻（域外，5 费）

**卡面**〔原典〕
> 【限定】（红月）使斯卡琳获得**+150+200**，使**手牌中的所有「红月」**花费减二。

**机制拆解**
5 费：斯卡琳 +150 攻击力 / +200 防御力；手牌中所有红月减二费。

〔留白〕+150+200 是否永久？（对照勇气明写"永久"，月见明写"直到下个敌方回合结束"，此处未写）

〔推算〕"手牌中的所有红月减二费"——〔推算〕红月四式各 5 费（凝聚 8 费），减二后为 3 费（凝聚 6 费）。〔推想〕若手上有 3 张红月，则一次凝刻省下 6 费。

〔推算〕**它的价值与手上红月的数量成正比**，所以最佳时机是"手上握着多张红月时"。〔推想〕而红月的来源是绯红之月（随机 1 张）与红月·凝聚（给 2 张）——〔推算〕**凝聚是凝刻的最佳搭档**：凝聚给两张红月，凝刻给它们减费。

**数值分析**
+150/+200 的面板提升：〔留白〕她的天赋施工中，基础面板未知。〔推算〕对照莉莉亚的月见（+150/+100）、伊芙格林的觉醒（150A/200D）。

〔推想〕**+150 攻击力对她的意义**：红月·过载「造成等同于斯卡琳攻击力的魔法伤害，平均分配至所有敌方目标」、红月·无限「将斯卡琳的攻击力五等分」。〔推算〕两张牌的伤害都基于她的攻击力，所以凝刻是它们的**放大器**。

**构筑定位**
域外，不占构筑位。来源：绯红之月（随机）、红月·凝聚（确定给一张）。

〔推想〕它是红月体系中的**buff 位**：给面板 + 给减费，不直接造成伤害。

**叙事关联**〔推想〕
"红月·凝刻"——〔推想〕"凝"是凝固、凝聚；"刻"是雕刻、时刻。

〔推算〕红月四式的命名结构：**凝刻、无限、过载、凝聚** ——〔推想〕四个词都是**物理／工程术语**：
- 凝刻：凝固 + 雕刻（一个静态的、被定住的时刻）
- 无限：infinity（数学）
- 过载：overload（电学／机械）
- 凝聚：condense（物理）

〔推想〕**红月四式用的是科学语言，而绯红链前三级用的是学术语言（原质、灵究、极限）。** 〔原典〕斯卡琳是魔力学三定律的归纳者——〔推想〕**她的牌名全部是术语，没有一个诗意词。**

〔推算〕对照其他英雄的牌名：莉莉亚（苍白之月、月见、弥望、逐月——诗意）、伊芙格林（狂风呼啸、永恒的记忆、与风同在——抒情）、诺维安（勇气、未来、新章、故事与歌——朴素）、赫琉思（光芒尖端、灼光、日冕——意象）。

〔推想〕**斯卡琳是唯一一位牌名全是术语的英雄。** 〔原典〕「现代魔法是目前唯一一种完全掌握作用原理的魔法体系。这意味着它可以被系统性地学习、教授与发展。」〔推想〕**她是那个"完全掌握原理"的人，所以她的牌名全是原理。**

〔推想〕"凝刻"——〔原典〕她在分娩之夜「成功地让孩子的灵魂**沉睡**在月色中，**等到**这场关于「禁忌」的封锁结束以后**再唤醒**」。〔推想〕**一个被凝固、被定住的时刻**：孩子在月色中停住了，等着。

〔推想〕而它的效果是"+150+200"与"减二费"——〔推想〕**凝固的时刻给了她力量，也让后续的牌变便宜。** 〔留白〕归档者的联想。

### 7. 红月·无限（域外，5 费）

**卡面**〔原典〕
> 【限定】（红月）将斯卡琳的攻击力**五等分**，**随机**分配至**五个**敌方目标。己方回合结束时，**若手牌中没有「红月·无限」，将一张「红月·无限」加入手牌**。

**机制拆解**
两段：
1. 攻击力五等分，随机分配至五个敌方目标
2. **回合结束时若手上没有它，就补一张** —— 自我回收

〔推算〕**第 2 段是全项目唯一的"被动自动回手"机制**：它不需要你打出，只要在回合结束时手上没有它就自动生成一张。〔推想〕对照其他"生成自身"的牌都需要主动打出才触发——英雄水晶／传召水晶／贤者之石是打出时"加入卡组"（生成），莫伊卡天赋是"【返场】加入手牌"（被消灭时触发），而红月·无限是**每回合结束自动检查并补齐**。〔推想〕这让它成为一张"你永远丢不掉"的牌。

〔推想〕这意味着：**只要打出它，它就会在回合结束时回到手上，可以无限次使用。** 〔推算〕这是"无限"这个名字的机制化。

〔推算〕它对"使用过五张红月"计数的贡献：**每张都算一次**，所以反复打出无限可以独自刷满 5 次计数。

〔推算〕最短路径：绯红之月随机给到无限（1/4 概率）→ 打出（计数 1）→ 回手 → 打出（计数 2）→ … → **5 个回合刷满**。〔推想〕若随机给到的不是无限，则需要红月·凝聚（确定给凝刻 + 无限）来获得它。

〔推算〕伤害计算：攻击力五等分，随机分配至五个敌方目标。〔留白〕她的基础攻击力未知（天赋施工中）。〔推算〕若凝刻给了 +150，则假设基础 200A → 350A ÷ 5 = **每份 70 点**。

〔推想〕**五等分意味着目标越少，每份越重**：
- 敌方 5 个单位 → 每份 70，各受 70（〔留白〕随机分配可能重复命中同一目标）
- 敌方 1 个单位 → 5 份全打它 → **350 点**
- 敌方 0 个单位 → 〔留白〕如何处理？

〔推算〕对照红月·过载「造成等同于斯卡琳攻击力的魔法伤害，**平均分配**至所有敌方目标」——〔推想〕两张牌都是"总量固定、分配可变"，但：
- 无限：**五等分**，随机分配至**五个**目标（分五份，随机投放）
- 过载：**平均分配**至**所有**敌方目标（按目标数等分）

〔留白〕两者的差异在原典措辞上很微妙，实际结算可能相同也可能不同。

〔推算〕伤害类型：〔留白〕**未写明**！〔推算〕对照红月·过载明写"魔法伤害"，凝刻无伤害，凝聚无伤害，无限**只写"将攻击力五等分随机分配"，未写伤害类型**。〔推想〕她是法师·魔法使 → 应为魔法伤害，但卡面未写。

**数值分析**
5 费、可无限复用。〔推算〕**每回合 5 费换 350 点分散伤害**（假设 350A），且计入红月计数。

〔推想〕这是红月体系中**唯一可持续输出的牌**（凝刻是 buff、过载是一次性大伤害、凝聚是资源）。

〔推算〕它的自我回收也解决了"红月不够用"的问题：〔推算〕绯红之月只随机给 1 张，凝聚给 2 张，而绯红的真实需要"使用过五张"——**无限可以独自补足计数**。

**构筑定位**
域外，不占构筑位。来源：绯红之月（随机）、红月·凝聚（确定）。

〔推想〕**它是整套体系的引擎**：提供持续伤害 + 提供红月计数 + 自我回收。〔推算〕若绯红之月随机给到了它，整套牌的运转会顺畅得多；若给到的是过载或凝刻，则需要凝聚来找它。

**叙事关联**〔推想〕
"红月·无限"——〔推想〕"无限"（infinity）。

〔推算〕它的机制是**自我回收、可无限次使用**。〔推想〕名字与机制完全对应。

〔原典〕魔力学第二定律（魔能守恒）：「魔力与原质在统一量纲后总和**保持不变**」；第三定律：「转化过程中能量总和**保持不变**」。

### 8. 红月·过载（域外，5 费）

**卡面**〔原典〕
> 【限定】（红月）**在手牌中时，每使用一张「红月」，获得减一花费**。造成等同于斯卡琳攻击力的**魔法伤害**，**平均分配**至所有敌方目标。

**机制拆解**
两段：
1. **在手牌中时**的被动：每使用一张红月 → 自己减一费
2. 使用时：等同斯卡琳攻击力的魔法伤害，平均分配至所有敌方目标

〔推算〕第 1 段是**手牌中的被动减费**——〔推想〕这与凝刻的"手牌中所有红月减二费"是两种不同的减费机制：
- 凝刻：主动打出，一次性给手牌中所有红月减二费
- 过载：自己在手牌中被动累积减费（每张红月 −1）

〔推算〕若使用过 5 张红月，过载的费用为 5 − 5 = **0 费**。

〔推想〕**这是全项目唯一一张"可以减到 0 费的高费牌"**（对照苍白天球 13 费最多减到 9～10、绯红的真实 18 费最多减到 13）。

〔推想〕**"平均分配"意味着对手单位越少，单体伤害越高** ——〔推算〕这与红月·无限的"五等分随机"方向相同（总量固定，分布可变）。

**数值分析**
5 费（可减至 0）、等同攻击力的全体魔法伤害。〔推算〕若减到 0 费，则**免费造成等同攻击力的全体伤害**。

〔推算〕对照其他全体伤害：
| 卡牌 | 费 | 伤害 | 分配 |
|---|---|---|---|
| 红月·过载 | 5（可减至 0） | 等同攻击力 | 平均 |

〔推算〕但她的天赋施工中 → 基础攻击力未知 → **这张牌的实际强度无法评估**。

**叙事关联**〔推想〕
"红月·过载"——〔推想〕"过载"（overload）是电学／机械术语：**超过设计承载能力**。

〔原典〕「她本人却因**魔力耗尽**死去。」〔推想〕**过载导致耗尽。**

### 9. 红月·凝聚（域外，8 费）

**卡面**〔原典〕

**机制拆解**
8 费：+3 魔力上限 + 给两张红月（凝刻与无限，**确定而非随机**）。

〔推算〕**它是链条中唯一"确定给牌"的红月来源**（对照绯红之月是随机）。〔推想〕所以它是**找回无限**（自我回收引擎）与**凝刻**（buff + 减费）的可靠手段。

〔推想〕它是**中继站**：把魔力上限与手牌同时推上去。

## D. 终点：绯红的真实（域外，18 费）

**卡面**〔原典〕
> 【限定】**使用过五张「红月」后，加入手牌**。在手牌中时，每使用一张「红月」，获得减一花费。使**除斯卡琳外的所有单位攻击力为0**，直到下个己方回合结束。**下个己方回合开始时，将三张「红月」加入手牌，使其花费为0**，回合结束时，**消灭斯卡琳**。

### 机制拆解：五段

| 段 | 内容 | 性质 |
|---|---|---|
| 1 | **使用过五张红月后，加入手牌** | 入场条件（不可构筑、不可检索，只能"长出来"） |
| 2 | 在手牌中时，每使用一张红月 → 自己减一费 | 被动减费 |
| 3 | 使除斯卡琳外的**所有单位攻击力为 0**，直到下个己方回合结束 | 全场压制 |
| 4 | 下个己方回合开始时，将**三张 0 费红月**加入手牌 | 资源爆发 |
| 5 | **回合结束时，消灭斯卡琳** | 自毁 |

〔推算〕**这是全项目唯一一张"以自身退场为代价"的牌**，也是唯一一张**由使用计数决定入手**的牌（对照其他域外牌都是由特定牌"生成"或"洗入"）。

〔推算〕第 3 段"除斯卡琳外的所有单位攻击力为 0"——〔推想〕**双方都受影响**（写"所有单位"，未限定敌方）。〔推算〕所以这是一个"清场到只剩她一个人能打"的效果。

〔推算〕配合红月·过载（等同她攻击力的全体魔法伤害）与红月·无限（攻击力五等分）：**对手攻击力为 0，她攻击力不变** → 第 4 段给的三张 0 费红月可以无风险打出。

〔推算〕**完整的终局序列**：
1. 使用 5 张红月 → 绯红的真实加入手牌
2. 打出它（18 费 − 已用红月数 × 1；若已用 5 张则 13 费）
3. 全场（除她）攻击力归零，持续到下个己方回合结束
4. 下个己方回合开始 → 三张 0 费红月入手
5. 打出三张 0 费红月（假设是过载 ×3 或无限 ×3）→ 每张造成等同她攻击力的伤害
6. 回合结束 → **消灭斯卡琳**

〔推算〕第 5 步的伤害：若三张都是过载（等同攻击力的全体魔法伤害），则 3 × 攻击力。〔留白〕三张红月是随机的还是可选的？卡面只写"将三张「红月」加入手牌"，未说明种类。

〔推想〕**这是全项目理论伤害上限最高的一次爆发**：3 × 攻击力（无上限，取决于凝刻叠加）+ 对手完全无法还手。

〔推算〕而 1000 点信仰防御力 ÷ 3 = **334 点攻击力**即可一击摧毁信仰（若伤害能打到信仰）。〔留白〕过载写"平均分配至所有敌方目标"，"目标"是否含信仰？未写明。

### 数值分析

〔推算〕18 费的可达性：
- 自然上限 12
- 链条 +7（原质 1 + 灵究 1 + 极限 2 + 之月 3）
- 凝聚 +3
- **合计最高 22**，硬上限 24 之内 ✓
- 18 费 − 减费（每用一张红月 −1，理论最多减 5 以上）→ 最低可能 13 费甚至更低

〔推算〕**13～18 费需要魔力上限至少 13** → 必须完成转化链。〔推想〕这正是 dsh 归档页说对的那句："18 这个数字几乎是刻意的：就算减满五费，你也得把魔力上限推到 13 以上——而能推上限的，只有她自己。"

〔推算〕**但 dsh 漏了一件事**：转化链的入口绯红原质**不带【限定】**，可以在她不在场时打出；而链条后三级（灵究、极限、之月）中，之月也不带限定。〔推想〕所以**推上限这件事不需要她在场**，只有红月四式与绯红的真实需要。

〔推算〕当前状态（天赋施工中）：
- 可用：绯红原质（+1 上限）、绯红灵究（+1 上限 + 抽 1）、绯红极限（+2 上限 + 抽 2）、绯红之月（+3 上限）→ **链条的"推上限"部分完全可用**
- 不可用：红月四式（全部【限定】）、绯红的真实（【限定】）→ **7/10 张牌不可用**

〔推想〕**所以斯卡琳编组目前是一套"只能推魔力上限、不能做任何事"的牌。** 〔推算〕+7 上限本身没有意义，因为通用池里没有需要高魔力的大招（最高 8 费：我们的歌，属新的勇者阵营）。

### 构筑定位

域外，不占构筑位，且**不可检索**（只能由"使用过五张红月"这个计数产生）。

〔推算〕**这是全项目获取条件最苛刻的一张牌**：
- 需要斯卡琳在场（天赋施工中 → 不可能）
- 需要使用过 5 张红月（红月只有 4 种，需要靠无限的自我回收或凝聚的补给刷计数）
- 需要魔力上限 ≥13（需要完成转化链）
- 需要活到第 13～18 回合
- 打出的代价是**她自己被消灭**

〔推想〕五重条件，每一重都极难。〔推算〕这是一张**为"设计意图"而非"实际可用"而存在的牌**。

- 苍叶「本单位行动后，**消灭该单位**」（自我牺牲的一次性箭）
- 绯红的真实「回合结束时，**消灭斯卡琳**」

〔推想〕**一张 1 费的域外小单位，和一张 18 费的终极牌，用的是同一个词。** 〔推想〕在这个规则体系里，"消灭"是最彻底的移除——不是返回手牌（相位移动）、不是洗入卡组（返场）、不是禁锢（还活着但不能动），是**消灭**。

〔原典〕她被"秘密杀害"。〔推想〕**"消灭斯卡琳"就是那件事。**

〔推想〕最后一个细节：这张牌是**域外**的。〔原典〕「域外：该卡牌**无法在收藏中获得**。」〔推想〕**真相无法被收藏。** 它不能被拥有、不能被展示、不能在图鉴里查到——它只能在特定条件下（使用过五张红月）**自己出现**，然后消灭说出它的人。

〔留白〕以上全部为归档者基于原典真相节与卡面的推想。原典从未说明这张牌与剧情的关系。但"绯红的真实"这个名字（对应原典的「### 真相」章节）、"消灭斯卡琳"的效果（对应"魔力耗尽死去"与"秘密杀害"）、以及"域外"的属性（对应"被划为禁忌、被掩盖"），三者的对应密度极高。

〔推想〕**这是全项目叙事与机制咬合最深的一张牌，而 dsh 归档页对它的解读停留在"赢得干净，也付得干净"这个战术层面。**

### 存疑与留白（绯红的真实）

1. "使用过五张红月"的计数：是使用次数还是不同种类数？（红月只有 4 种，若要求不同种类则最多 4，永远无法达成 → **应为使用次数**）
2. 三张红月的种类：随机、可选、还是固定？
3. "所有单位攻击力为 0"是否包括己方？（写"所有单位"，应为双方）
4. 攻击力归零后，依赖攻击力的牌（过载、无限）是否失效？（**除斯卡琳外**，所以她自己的仍有效）
5. "消灭斯卡琳"是否触发【返场】？（英雄返场是"被消灭时洗入卡组"——若触发，则她会被洗回卡组而非真正退场）
6. 18 费减费的下限（能否减到 0）
7. 平均分配的伤害能否打到信仰
8. 这张牌本身是否算"红月"？（它不带（红月）标注 → 应不算）

## 编组总结

### 数值画像

| 维度 | 赫琉思 | 斯卡琳 |
|---|---|---|
| 条目总数 | 8 | 10 |
| 天赋 | **2 张（施工中）** | **0 张（施工中）** |
| 可收藏专属魔法副本 | 6 | 6 |
| ＋通用池 25 | 31（缺 9） | 31（缺 9） |
| 域外牌 | 2（光辉、日冕） | **7**（灵究、极限、红月四式、绯红的真实） |
| 域外比例 | 25% | **70%**（全项目最高） |
| 带【限定】 | **6/8 = 75%**（全项目最高） | 5/10 = 50% |
| 最高单卡费用 | 12（日冕） | **18**（绯红的真实，全项目最高） |
| 费用中位数 | 3 | 5 |
| 单位生成牌 | **0** | **0** |
| 当前可用性 | 天赋存在（数值未定）→ 结构上可运行 | **天赋缺失 → 完全不可运行** |

### 阵营层面的三个结构性问题

**1. 同盟军凑不满 40 张。**〔推算〕可收藏副本 12（光芒尖端2 + 灼光1 + 太阳蚀刻2 + 普照1 + 阿波罗经络1 + 绯红原质4 + 绯红之月1）+ 通用池 25 = **37**。〔推算〕即使把两位英雄卡与赫琉思的 1 张天赋都计入（原典未定义是否占卡组位），也只有 **38～40**，且没有任何冗余。〔推想〕**这个阵营在设计上还没有落地。**

**2. 同盟军没有任何单位牌。**〔推算〕18 条目中 0 张单位。〔推想〕对照新的勇者（芬特罗德属通用，格兰蒂亚两张 + 苍叶 + 树人 = 4 种单位）。〔推想〕**两位同盟军英雄都是孤身作战**：赫琉思靠 6 张魔法牌破防，斯卡琳靠 10 张魔法牌推上限。

〔推想〕这与原典的人物处境吻合：〔原典〕赫琉思「在荷珀死后无法找到希望，**不知所踪**」；斯卡琳「秘密杀害……在斯卡琳分娩的夜晚，同盟军发起了突袭。荷珀这才明白人类联邦的说辞只是借口，最终**战死在房前**」——〔推想〕**她死的时候，身边只有丈夫一个人。**

〔推算〕而"调度"（通用，2 费，「若有己方英雄，抽两张单位」）对同盟军的价值极低：只能抽到通用的芬特罗德。〔推算〕"魔力附加"（需己方法师）对斯卡琳可用（她是法师·魔法使），但**目标是"战士或射手"**，而阵营里只有赫琉思是射手 → 只有他一人能吃到。

**3. 斯卡琳的"觉醒"是悬空引用。**〔推算〕绯红之月写"使斯卡琳觉醒"，但她没有觉醒面板（全项目只有莉莉亚与伊芙格林有）。〔推想〕这是全项目**最明确的未完成设计**——一张可收藏的 L 品质牌，写着一个无法执行的操作。

### 两位英雄的设计对照

| | 赫琉思 | 斯卡琳 |
|---|---|---|
| 核心动词 | **解除**（防御） | **累积**（魔力上限） |
| 链条结构 | **生成**（普照→光辉→日冕，每级"加入卡组"） | **转化**（原质→灵究→极限→之月→红月，卡数不变） |
| 链条级数 | 3 | 4 + 红月四式 + 真实 |
| 链条入口 | 普照（2 费，上限 **1**） | 绯红原质（2 费，上限 **4**） |
| 终局牌 | 日冕（12 费，扣自己 100% 血，200 全体 + 溢出打信仰） | 绯红的真实（18 费，全场攻击力归零 + 三张 0 费红月 + 消灭自己） |
| 终局代价 | **自己的防御力** | **自己的生命** |
| 能否打信仰 | **✓**（日冕溢出） | 〔留白〕未明确（过载／无限写"敌方目标"） |
| 意象 | 太阳、光、日冕 | 红月、绯红、术语 |
| 牌名风格 | 意象词（光芒、灼光、普照、光辉、日冕） | **术语词**（原质、灵究、极限、过载、凝聚、凝刻） |
| 类型 | 射手（物理） | 法师·魔法使（魔法） |
| 种族 | 精灵 | 人类 |
| 原典结局 | 不知所踪 | 被秘密杀害，魔力耗尽而死 |

〔推想〕**两人的终局牌是同一个模板的两种强度**：都以自己为代价，都在最后造成大范围伤害。〔推算〕赫琉思付出防御力（可被回复），斯卡琳付出生命（不可逆）。

〔推想〕对照原典：〔原典〕赫琉思是精灵（「千岁以上的自然寿命」「较强的再生能力」），所以他付出的是可以再生的东西；斯卡琳是人类（「驯服魔力的短生种」），她付出的是不可再生的东西。

〔推算〕**两个种族的寿命设定，被写进了两张终局牌的代价里。**

〔留白〕归档者的推想。但这个对应（长生种付出可再生资源 / 短生种付出生命）与原典种族设定的一致性很高。
