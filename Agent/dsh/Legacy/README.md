# 长歌 · 归档页（dsh）

这是《长歌》游戏企划的一份**只读归档**，不是设定集。所有产物都写在 `dsh/` 目录里；
项目其余部分只被读取。

## 打开

直接双击 `index.html`。页面全部是静态文件，不需要服务器、不需要联网：

- 卡图是内联 SVG 文件（`assets/img/cards/*.svg`），不依赖外部图片；
- 图鉴筛选、构筑沙盘、战场射程演示、关系星图都是原生 JavaScript，无第三方库；
- 沙盘的牌表存在浏览器 `localStorage`（键名 `hisstory.deck.v1`）。

## 本轮（第四轮）改了什么

1. **卡面重录**：按现版 `CardsDesign.md` 重新解析全部 86 条，逐条比对出 17 处文本变更
   （动词体系、绯红之月的【限定】与「开发」、莉莉亚【觉醒】的「本场对战」等）。
2. **动词表**：加入＝生成、洗入＝移动、抽取＝检索、转化为＝变身、返回＝移回、开发＝生成。
   附四条结论：域外闭环、上限的含义、卡组会膨胀、孤本与永不耗尽。
3. **作者裁定**：并入规则手册第 12 节（数值与费用／伤害与目标／时序与触发／持续与永久／构筑），
   从此它们是规则，不再是推想。
4. **规则错误修正**：骑士没有「移动且攻击」（游侠独有）；魔法使没有「不受反击」（炼金术师独有）；
   英雄与天赋在构筑合成为一张牌；0 费不等于【机动】；莉莉亚觉醒要走「苍白百合→苍白之月」；
   大奇迹按阵亡数累加并排除英雄；御风是五张；觉醒转换五组；「开发」只有三张牌在用；米莉卡并非全场最贵。
5. **关系标签**：新增「前置」「对照」，9 条跨阵营连线降为「对照」——它们不会同框。
6. **战场**：删去「五段」的说法，改为「战场由随机地图决定，末端战区必定存在且不可被占领」。
7. **人物**：莫伊卡统一为「她」；「七位魔王军领袖」（原「军团长」为过时说法）；阿尔法职业两处记载不同，加冲突标注不裁定。

9. 页脚与本文档统一口径；「弓箭手」是小说用词、「射手」是单位类型，不是笔误。

## 重建

```powershell
cd dsh/src
python build.py     # 输出 101 个页面（101 = 7 个站点页 + 8 英雄 + 86 卡）
python check.py     # 扫描全站本地链接
```

只依赖 Python 标准库：`data_cards.py` 是卡牌数据（由 `gen_cards.py` 从 `CardsDesign.md` 解析生成），
`meta.py` / `meta_world.py` / `meta_rules.py` 是全部文案与结构，`art.py` 用手写 SVG 生成卡图、徽记与主视觉。

## 标注体系

- **原典**：项目文件里已有明文，照录或仅作排版；
- **草案**：项目文件中的构想，尚未定稿；
- **推想**：归档者为了读懂而补写的连接与解释，不构成设定（主视觉题记、阵营格言、编组名、英雄小标题、机制的来历均属此列）；
- **施工中**：原典尚未写到的部分（赫琉思的两张天赋、同盟军其余三人的天赋、魔王军卡池）；
- **待确认**：原典内部有歧义或留白，归档不代为补完。

「肥鱼碎碎念」是归档者的读卡笔记，单独成块，不进入正文结论。

## 转录规则

- 卡牌文本原文照录，包括括注与「」；不做数值平衡，不改措辞。
- 世界观照录四条概念（魔力／魔法／原质／魔器）与三大定律，不增补设定。
- 「真相」一节不转录，只在其他文本里留暗示。
- 关系连线（生成／转化／条件／检索／同源／联动／前置／对照）由归档者从卡牌文本整理，原典并未逐条声明。
- 莫菲属魔王军第七位领袖「梦之掌司」。

## 与原典的差异

- 前几轮经作者同意改过 14 处错字（Outline.md 8 处、HisStory-Game/Outline.md 2 处、CardsDesign.md 4 处）；
  本轮没有再改原典任何一个字。
- 本轮 CardsDesign.md 里的 17 处变化是**规则变更**，不是错字：归档照录，差异列在规则手册第 14 节。
- 「她的梦想」原稿把『枷锁』误写成『禁锢』（卡池没有名为「禁锢」的牌），作者确认后已改回；归档按现稿照录，并把这笔记在归档注里。
- 世界观与战争史只做排版与分节；「真相」一节不转录，只保留一句指认。
